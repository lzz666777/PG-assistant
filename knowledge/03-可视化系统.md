# 可视化系统

## 总体结构
四个模块：价格地图、站点账单、治理沙盘、反馈中心。
底层是数据层（多源数据 + 证据），中间是指标层（全成本、价格偏差、有效供给、占位、排队），上层是应用层 + 智能体。

## 1. 价格地图
- 图层：电网归属（国网/南网/地方电网/园区/未知）、全成本、价格偏差、套路指数。
- 筛选：城市、区、电网、品牌、价格区间。
- 图表：站点地图（颜色=价格偏差/全成本）、Top20 差价站点、价格结构堆叠图。
- 交互：点站点进入“站点账单”；切换“平台价/实付价/全成本”。
- 结论：低价不等于低全成本；价格偏差集中在哪些电网/品牌/区域。

## 2. 站点账单
- 顶部：站名、电网标签、运营商、地址、核验时间、证据等级。
- 价格拆解：电费、服务费、停车费、最低消费、其他；平台价 vs 现场小程序价 vs 实付。
- 图表：24 小时价格/占用曲线；价格偏差哑铃图；评论关键词。
- 信息：有效空闲概率、占位/坏桩标记、停车规则。
- 交互：看证据照片、看用户反馈、提交纠错。

## 3. 治理沙盘
- 用户侧：价格敏感/时间敏感/排队厌恶三种偏好，推荐站点/时段。
- 运营商侧：占位费（免费宽限、阶梯费率、封顶）、预约押金、扩容站数；KPI：等待、周转率、收入、投诉率。
- 政府侧：价格透明度低 + 投诉高 + 有效供给缺口大的区域，输出治理优先级。
- 交互：拖滑块，KPI 和排名实时变；可对比现状/方案 A/方案 B。

## 4. 反馈中心
- 反馈类型：价格不符、占位、坏桩、排队、环境/服务。
- 入口：扫码/网页；定位、拍照、小票、匿名。
- 处理：审核 → 更新价格/状态 → 反馈用户 → 信用分/申诉。
- 展示：问题地图、待核验列表、最近更新。

## MVP 与最终版
- MVP：价格地图 + 站点账单 + 占位仿真（三页），用 20—30 站样本跑通。
- 最终：四模块 + 预测 + 推荐 + 智能体；7 个分析问题对应到视图。
- 技术建议：Streamlit + pandas + Plotly；地图先用 st.map，后续换 pydeck/Plotly Mapbox；数据表用 parquet/CSV。

## 设计原则
- 先跑通再美化；每个图配一句结论。
- 价格旁边必须带“核验时间 + 证据等级”。
- 不把“实时地图”当卖点；卖点是“可信价格、有效供给、治理”。
