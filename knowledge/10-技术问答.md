# 技术问答

## Python 的 `pathlib.Path` 是干什么的？
`pathlib` 是 Python 自带路径库，`Path` 表示文件/文件夹路径。
```python
from pathlib import Path
DATA = Path(__file__).parent / "data" / "sample.csv"
```
`__file__` 是当前脚本路径，`.parent` 是脚本所在文件夹，`/` 用来拼路径。
好处：不管从哪个目录启动，都能找到脚本旁边的数据；Windows 用 `\`、Mac/Linux 用 `/`，Path 自动处理。

## Python 的条件表达式（三元表达式）怎么写？
```python
view = df if district == "全部" else df[df["district"] == district]
```
语法：`值1 if 条件 else 值2`。条件为真取值1，否则取值2；`else` 不能省。
等价于 if/else。`df[df["district"] == district]` 是 pandas 布尔索引：先得到 True/False 列，再筛行。
注意：`"district"` 是列名，`district` 是变量，不要混。

## pandas 的 `.unique()` 和 `.nunique()` 有什么区别？
- `.unique()` 返回去重后的具体值（NumPy 数组），按出现顺序，包含 NaN 一次。
- `.nunique()` 返回去重后的数量（整数），默认不把 NaN 算进去。
```python
df["district"].unique()          # array([...])
df["district"].nunique()         # 5
df.nunique()                     # 每列的唯一值数量
df["district"].nunique(dropna=False)
```
DataFrame 没有 `.unique()`；要写 `df["列"].unique()`。

## pandas 怎么读 CSV？路径报错怎么办？
```python
import pandas as pd
from pathlib import Path
df = pd.read_csv(Path(__file__).parent / "data" / "sample.csv", parse_dates=["timestamp"])
```
`FileNotFoundError` 通常是相对路径问题：`pd.read_csv("data/x.csv")` 相对于启动目录，不是脚本目录。用 `Path(__file__).parent` 拼绝对路径。

## Streamlit 三页是什么意思？
一个 Streamlit 应用，左侧 `st.sidebar.radio` 切换三个页面/视图，不是三个网址。
示例：
```python
page = st.sidebar.radio("页面", ["城市全景", "站点详情", "情景沙盘"])
if page == "城市全景": ...
elif page == "站点详情": ...
else: ...
```
MVP 三页：城市全景（地图+指标）、站点详情（选站+曲线+表）、情景沙盘（滑块+KPI+对比图）。

## Streamlit 的 `st.metric` 怎么加图标？
`icon` 只接受一个 emoji 或一个 Material 图标名：
```python
st.metric("充电桩数", 80, delta="7%", icon="⚡")
st.metric("充电桩数", 80, delta="7%", icon=":material/ev_station:")
```
不能传 PNG/SVG 路径；传路径会报 `not a valid emoji`。
Material 图标名查 https://fonts.google.com/icons；Streamlit 支持的名字可用：
```python
from streamlit.material_icon_names import ALL_MATERIAL_ICONS
print([x for x in ALL_MATERIAL_ICONS if "ev" in x or "charg" in x])
```

## Material 图标是什么？
Google Material Symbols 图标字体，用名字调用，不是图片。Streamlit 写法 `:material/名字:`，例如 `:material/bolt:`、`:material/battery_charging_full:`。
VS Code 里配置显示语言不会翻译扩展面板；Material 图标是单色字体图标，跟主题色走。

## SVG 是什么？怎么在 Streamlit 里用？
SVG 是可缩放矢量图形，用 XML 描述路径，放大不失真；PNG 是像素图。
Streamlit 的 `st.image` 支持 SVG 字符串：
```python
from pathlib import Path
svg = Path("icon.svg").read_text(encoding="utf-8")
st.image(svg, width=48)
```
`st.metric` 的 `icon` 不收 SVG；要显示 SVG，用 `st.image` 或 HTML `<img>`。

## Streamlit 报 `StreamlitAPIException: ... is not a valid emoji` 怎么办？
说明你把图片路径传给了 `icon`。改成 emoji 或 Material 名称：
```python
icon="⚡"  # 或 icon=":material/ev_station:"
```
要显示原图，用 `st.image`，不要塞进 `icon`。

## Streamlit 的 `st.columns` 怎么用？
```python
left, right = st.columns([2, 1])   # 左 2 份宽，右 1 份宽
with left: st.map(df, latitude="lat", longitude="lng")
with right: st.bar_chart(df.groupby("name")["queue"].mean())
```
`st.columns(3)` 是三列等宽；里面放 `st.metric` 就是指标卡。

## Streamlit 图表怎么选？
先用内置：`st.line_chart`、`st.bar_chart`、`st.map`、`st.dataframe`。
需要颜色/气泡/交互地图时，再用 Plotly：
```python
import plotly.express as px
fig = px.scatter_mapbox(df, lat="lat", lon="lng", color="price", size="piles")
fig.update_layout(mapbox_style="open-street-map")
st.plotly_chart(fig)
```
不要一开始学三个库；先跑通 pandas 5 个操作 + Streamlit 7 个组件。

## Streamlit 的 `use_container_width` 还能用吗？
新版本不推荐；用 `width="stretch"` 或 `width="content"`。普通图表默认会撑满容器，按钮默认按内容宽。

## Git 装了吗？怎么和 GitHub 绑定？
检查：
```powershell
git --version
git config --global user.name
git config --global user.email
```
HTTPS 方式：第一次 push 会弹浏览器授权，Git Credential Manager 保存凭据；之后不用每次登录。
SSH 方式：需要生成密钥并加到 GitHub；没配 SSH 时 `ssh -T git@github.com` 会 `Permission denied (publickey)`，不影响 HTTPS。

## GitHub 报 `Recv failure: Connection was reset` / `Failed to connect to github.com:443` 怎么办？
先判断网络：`curl -I https://github.com`。如果直连不通、走代理能通，给 Git 配代理（Clash 常见端口 7897）：
```powershell
git config --local http.proxy http://127.0.0.1:7897
git config --local https.proxy http://127.0.0.1:7897
git push
```
不想用代理时：
```powershell
git config --local --unset http.proxy
git config --local --unset https.proxy
```
Git 不会自动使用 Windows 系统代理，所以“浏览器能开”不等于“Git 能推”。

## VS Code 里的 DeepSeek Harness 扩展是什么？
社区扩展 `lucasliang.harness-connector-deepseek`，把本机 `dsh web` 的会话接到 VS Code 侧边栏；它不重新实现 Agent，也不等于 Copilot 的“自定义智能体”。
安装：
```powershell
code --install-extension lucasliang.harness-connector-deepseek
```
需要本机有 DSH Host（`dsh web`），默认 3080；桌面版端口会变，扩展可自动发现。
Copilot 的“用户/工作区”自定义代理只是提示词，不是 DSH 运行时，两者不要混。

## Python 生成 Word 文档用什么？
`python-docx`。基本流程：
```python
from docx import Document
doc = Document()
doc.add_heading("标题", level=1)
doc.add_paragraph("正文")
doc.save("out.docx")
```
中文字体要同时设 `run.font.name` 和 `w:eastAsia`；表格用 `add_table`，页脚页码用 `PAGE` 域。
生成后重新打开检查段落、表格、关键标题；需要看版面时用 LibreOffice/office_render 渲染。

## 报错看不懂时怎么排查？
1. 看最后一行错误类型和文件路径。
2. 看是“找不到文件”“类型不对”“网络不通”还是“权限”。
3. 把错误信息、代码行、运行目录一起发给助手。
4. 先做最小复现：删到只剩几行，确认哪一行触发。
