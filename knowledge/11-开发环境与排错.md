## 启动 Streamlit
```powershell

C:\电脑应用\Python\.venv\Scripts\streamlit.exe run streamlit_test.py
```

- 每次 push 后 Actions 自动部署；网址 `https://lzz666777.github.io/PG-assistant/`。
- 页面改完不生效：等 Actions 跑完，Ctrl+F5 强刷；检查 `assets/config.js` 是否被缓存。

- 地址：`https://charging-project-tutor.3620028475.workers.dev`
- 健康检查：`/health` 返回 `{"ok":true,"model":"deepseek-flash"}`。

## 常见错误对照
| 错误 | 常见原因 | 处理 |
|---|---|---|
| `FileNotFoundError` | 相对路径/文件没建 | 用 `Path(__file__).parent`；先建 data 目录 |
| `StreamlitAPIException: not a valid emoji` | `icon` 传了图片路径 | 改 emoji 或 `:material/名字:` |
| `ModuleNotFoundError` | 没在 venv 里跑/没装包 | 用 venv 的 python/pip |
| `Recv failure: Connection was reset` | GitHub 直连被重置 | 配 Git 代理或开 VPN |
| `Failed to connect to github.com:443` | DNS/IP 不可达 | 代理、换网络、hosts |
| `403 Origin not allowed` | Worker 的 ALLOWED_ORIGINS 不含当前域名 | 改 Worker 变量并重新部署 |
| `Failed to fetch` | workers.dev 被墙/CORS/地址错 | 开代理、查 `/health`、查 CORS |
| `401` | 访问码不对/Key 失效 | 检查 ACCESS_CODE、重建 Key |
| `429` | 限流 | 等一会儿或调高限额 |

## 文件与备份
- 原始数据、代码、报告分别放目录；不要把所有东西丢桌面。
- Git + 网盘双备份；原始数据只读。
- 密钥、`.env`、账号密码不进 Git；用 `.gitignore` 排除。
