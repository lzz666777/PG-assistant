# 项目定位与背景

## 现有地图已经解决了什么
高德、百度、特来电、星星充电、小桔、云快充等已经提供：站点位置、导航、实时状态、标价、扫码支付。
再做一个“能看桩在哪”的地图，很难构成差异化，省奖都危险。

## 仍然没解决的四个问题
1. **电网与电价不透明**：用户不知道这个站由国网、南网、地方电网还是园区增量配电网供电，也不知道电费按什么政策、峰谷怎么分。
2. **平台价不等于实付价**：平台显示一个价，到站要扫另一个小程序；服务费、停车费、最低消费、会员价层层叠加。
3. **“空闲”可能是假的**：地图显示空闲，可能是坏桩、油车占位、充满不走，或者司机提前占位等低价电。
4. **反馈不可计算**：评论分散在各平台，价格投诉、坏桩、占位没有被结构化，无法变成可计算的数据。

## 三个转变
| 维度 | 现有地图 | 本项目 |
|---|---|---|
| 数据 | 单源实时状态 | 多源融合 + 证据分级 + 实地核验 |
| 分析 | 描述性：现在有什么 | 预测性 + 处方性：到站会怎样、该怎么做 |
| 对象 | 主要面向 C 端用户 | 用户 + 运营商 + 政府三侧 |
| 价值 | 查询工具 | 价格可信、有效供给与治理决策 |

## 四个重点
1. **电网归属与电价公开**：电网类型、电价政策、峰谷规则、价格构成；输出电网价格卡、同城比价。
2. **车位占用机制**：预约 + 充电验证 + 宽限 + 阶梯占用费；输出占位治理方案、费率仿真。
3. **价格透明化**：同站同时段同电量对比，拆出隐藏费用；输出价格偏差地图、可信度标签。
4. **用户反馈系统**：上报 + 证据 + 审核 + 信用 + 闭环；输出反馈中心、问题地图。

## 和现有产品的差异化
| 能力 | 高德/特来电 | 本项目 |
|---|---|---|
| 实时位置/导航 | 强 | 不重复，直接复用 |
| 平台标价 | 有 | 做平台价 vs 实付价审计 |
| 电网/电价政策 | 弱 | 电网标签 + 政策卡 + 峰谷 |
| 占位/有效供给 | 弱 | 假空闲识别 + 占位治理 |
| 用户反馈 | 有评论，未结构化 | 反馈中心 + 证据 + 更新 |
| 治理建议 | 无 | 价格/占位/扩容治理清单 |

## 和 2026 选址赛题的区别
2026 年赛题中已有“静态选址/新建站”方向。本项目不建新站，做运营期的价格可信、车位治理与到站决策，避开撞题。

## 答辩一句话
高德告诉你“现在多少钱”，我们告诉你“这钱为什么这么收、平台价是否可信、便宜是否真便宜、占位该不该收费、政府先治哪里”。
